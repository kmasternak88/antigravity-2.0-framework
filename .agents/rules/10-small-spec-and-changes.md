# 10-small-spec-and-changes

Zacznij od istniejącego repo i mierzalnego acceptance. Tiny: cel, pliki, ryzyko, test i rollback. Standard: contracts, DAG, error paths, test plan. Critical: threat model, recovery, niezależny reviewer i zewnętrzna zgoda. Założenia odwracalne zapisuj; nie pytaj o wszystko. Krytycznych niepewności finansowych/prawnych/destrukcyjnych nie zgaduj. Zmiana spec wymaga nowego digest approval.
